非线性阻尼单摆
数字孪生实验平台

面向课堂演示、物理实验教学和自主探究的 WebGL 实验平台。平台用 Three.js 呈现三维单摆，用带阻尼分裂的 Velocity Verlet 积分器计算运动，并提供实时参数、能量分析、相图、实验记录、报告导出和物理指导 AI。

功能概览

三维可视化使用 Three.js 渲染摆杆、摆球、灯光、运动轨迹和交互场景。
多种实验模式支持小角度、大角度、受迫、阻尼、混沌和自定义参数实验。
实时分析查看角度、角速度、动能、势能、机械能和相图变化。
实验记录按周期记录数据，支持 CSV 导出和可编辑实验报告页面。
重力测量根据摆长、周期数和总时间估算重力加速度并显示误差。
物理指导 AI结合当前参数、能量、积分器和最近记录回答实验分析问题。

物理模型与数值边界

系统模拟带阻尼、外部驱动的非线性单摆。无阻尼时，积分器采用 Velocity Verlet；阻尼项通过分裂更新加入，兼顾固定步长计算和长时间稳定性。

θ'' = −(g / L) sin(θ) − bθ' + F(t)
  • 固定仿真步长为 10μs，浏览器帧率只影响可视化呈现，不直接决定积分步长。
  • 图表刷新是 60Hz 采样显示，不等同于物理计算或跨设备的微秒级同步。
  • Velocity Verlet 属于适合保守系统的辛结构方法；加入阻尼或外部驱动后，系统本身不再是严格保守系统。
  • 能量漂移测试用于回归验证，不构成真实实验仪器精度或长期物理定律证明。
  • 小角度近似仅适用于较小摆角；大角度、强阻尼和混沌模式应结合完整方程解释。

AI 服务配置

生产环境使用 PHP SSE 接口，前端不会直接向 URL Time API 发送密钥。当前默认模型为 deepseek-v4.1-flash，默认接口地址如下：

api.urltime.cn

URLTIME_API_KEY=你的服务密钥
URLTIME_BASE_URLS=https://api.urltime.cn
URLTIME_MODELS=deepseek-v4.1-flash
AI_ROUTE_TIMEOUT=12
AI_TOTAL_TIMEOUT=60
TRUST_PROXY=1

中转地址可以带或不带 /v1，接口会自动拼接 /v1/chat/completions。多个地址使用英文逗号或换行分隔。

1Panel PHP 8.3 部署

  1. 执行 npm run build，将生成的 dist/ 内容上传到网站根目录。
  2. 网站根目录应包含 index.html 和 api/，不要再嵌套一层 dist/。
  3. 在站点目录或其上级目录创建未提交的 .env；当前 PHP 接口会读取这两个位置。
  4. PHP 运行环境选择 8.3 或更高版本，PHP-FPM 端口使用 1Panel 默认的 9000 即可，不需要对公网开放。
  5. 启用 openssl，确认 allow_url_fopen=On、output_buffering=Off、zlib.output_compression=Off。
  6. 确保 api/data/records/ 可写；访问 /api/health.php 应返回 configured:true、providers:1、models:1（使用自定义模型时按实际配置变化）。
生产环境不需要运行 Node。Node 仅用于本地开发和兼容测试；1Panel PHP 站点直接提供静态页面与 PHP API。首页底部已展示 ICP 备案号与公安备案号，并链接至官方查询平台。

数据、隐私与安全

  • 实验记录不会按明文 IP 保存，而是使用服务端盐值计算哈希后作为文件名。
  • 记录默认在最后一次更新后一小时过期；清空记录按钮会删除当前客户端对应数据。
  • API Key 只能配置在 PHP 环境变量或站点目录外的 .env 中，禁止写入 VITE_*、前端源码或公开仓库。
  • 生产站点必须启用 HTTPS，并限制 api/、.env、轮询状态文件和记录 JSON 的直接访问。
  • TRUST_PROXY=1 只应在反向代理可信且会清理伪造请求头时使用。
